# WindowPinDemo 设计

## 目标

做一个只验证核心技术的 macOS Demo：应用常驻菜单栏，用户把任意普通应用窗口置于前台后按 `⌥⌘P`，Demo 捕获该窗口并在相同位置创建一个始终位于普通窗口之上的实时镜像；再次按快捷键取消。首版不追求对镜像直接操作。

## 方案选择

采用公开 API 的实时镜像方案。ScreenCaptureKit 负责按窗口 ID 捕获画面，AppKit 创建无边框 `NSPanel` 并设置为 floating level，Carbon `RegisterEventHotKey` 注册不依赖辅助功能权限的全局快捷键。Core Graphics 的窗口列表用于从当前前台进程中找到最前面的普通窗口。镜像窗口鼠标穿透，因此不会伪装成真实可交互窗口。

没有采用 AX 反复 Raise，因为它并非持久层级且容易抢焦点；没有采用私有 CGS/SLS API，因为 Demo 目标是验证可公开分发的稳定路线；没有做鼠标点选模式，因为用户已选择“快捷键直接固定当前窗口”。

## 数据流与边界

快捷键触发后先记录当前前台 App，再读取按前后顺序排列的 CGWindow 信息，过滤掉本 Demo、非零 layer、透明及过小窗口，并映射到 `SCShareableContent` 中对应的 `SCWindow`。捕获帧进入 `AVSampleBufferDisplayLayer`。定时器只跟踪目标窗口几何变化与销毁；窗口消失时自动取消。

首次使用需要屏幕录制权限。无法捕获、没有候选窗口或权限不足时，通过菜单栏状态和系统提示给出反馈。DRM、安全窗口、菜单/弹窗、最小化及部分全屏场景不在 Demo 保证范围内。

## 验证

单元测试覆盖窗口候选过滤和 Quartz/AppKit 坐标转换；构建后在真实桌面上启动，验证快捷键注册、权限提示、实时捕获、浮动层及再次按键取消。
